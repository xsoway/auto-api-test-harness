# 运行测试套件 / 单接口

适用于单条调试、完整场景、冒烟和回归。完整命令和验收规则见 [跑批与验收](../../../docs/ai-api-testing.md#跑批与验收)。

1. 核对项目、执行范围与传输模式。实连前检查目标配置、授权范围、账号和数据。离线使用项目桩入口，或在 `ah debug` 与 `ah scheduled-run` 中显式传入 `--stub`。`LLMOFF=1` 关闭模型调用。
2. 单条或单场景可用项目 pytest 节点。批跑用 `ah scheduled-run <project> --suite <suite>`，按需使用环境、优先级和标签筛选。先检查匹配范围，并保留所需的场景前置步骤。带 `--run-live` 的项目入口按项目自身约定执行。
3. 记录退出码，读取本次报告中的实际执行、通过、失败和阻塞数。零命中或全跳过应单独汇报。对失败用例进入 [诊断流程](diagnose.md)。
